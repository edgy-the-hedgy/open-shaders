# Full Native raster input ABI v6 (Worker 03)

This is the source-level producer contract. It is not a claim that all game shader permutations or the Windows build have been validated. Lighting and final-color ownership are explicitly out of scope.

## Pass and ownership

The original opaque pass binds the four integer attachments using its existing MRT slots. The original raster operation performs depth/stencil and cutout visibility. No replay, additional indexed draw, per-draw shader substitution or per-primitive CPU token generation is permitted. The draw detours stamp metadata and call the original operation once. The scene owns raw publication independently of NativePBR, NativeLLF and NativeIBL.

## Resource ABI

| Slot | Resource | Format / contents |
| --- | --- | --- |
| 0 | MAIN | Engine format; alpha compatibility, no evaluated Lighting radiance |
| 1 | MOTION_VECTOR | Engine format; current/previous position motion |
| 2 | NORMALROUGHNESS | R10G10B10A2_UNORM; encoded geometric normal |
| 3 | IdentityUV | R32G32B32A32_UINT; draw row + 1, draw-local primitive, asuint(U), asuint(V) |
| 4 | ColorGradDepth | R32G32B32A32_UINT; RGBA8, half2 ddx(UV), half2 ddy(UV), asuint(SV_Position.z) |
| 5 | BasisFlags | R32G32B32A32_UINT; oct16 tangent, bitangent, normal, coverage/auxiliary flags |
| 6 | MaterialTechnique | R32G32B32A32_UINT; regular material/descriptor payload or technique-tagged auxiliary |
| 7 | MASKS2 | R16G16B16A16_UNORM; engine compatibility channels and binary participation witness in z |

Slot 5 flags: bit 0 front-face; bit 1 valid; bit 2 covered; bits 3–18 alpha UNORM16; bits 19–22 auxiliary kind flags (landscape, projection, eye, fur). Slot 6 landscape payload is eight half weights; projection is the original three-component projection vector and packed secondary UV; eye is the interpolated eye normal; fur is shell/root attributes. Regular material metadata is also in the draw table for every row, including auxiliary variants.

## Identity and draw records

Zero in slot 3.x is invalid. A nonzero identity is a one-based row in the immutable 80-byte RasterDrawRecord buffer. Slot 3.y is SV_PrimitiveID local to the draw for a single instance, or instance-relative ordinal times primitiveCount plus SV_PrimitiveID for supported instanced draws (the existing v6 decoder already supports this encoding). GPU-counted submissions use reserved bit 0 to identify bounded rather than exact counts: 65536 primitive stride and 65536 instances for supported instance-varying shaders; actual GPU arguments are not read back. Overflow/unsupported cases write the zero sentinel. The draw record contains geometry and material ordinals, optional TLAS instance, primitive count and base, optional native material index, actual index count/start/index-buffer byte offset/index width/base vertex, shader descriptors, instance count/first instance and indexed flag. Geometry/material ordinals are frame-local, not persistent object IDs. A partial range is distinct from a full range; its local primitive never aliases another draw. The current TLAS mapping is restricted to whole matching, unshifted single-instance triangle lists. A subrange or skin partition remains raster-local unless a verified mapping is supplied; do not infer a TLAS primitive from a raw start index alone.

The GPU table is one row per original draw (80 bytes), not per primitive. DX12 probe binds it at t1036 and reconstruction at t10. Both consumers bounds-check the row and primitive/instance range before reading it.

## Visibility certificate

The producer seeds actual OM/PS/IA state at opaque-pass entry and tracks subsequent binding changes. A certified draw requires a recognized custom integer-output permutation, the expected eight MRTs and main depth resource, replacement writes with full channel mask, and enabled depth test. Known writers without usable attributes write the zero sentinel. Recognized blended or unsupported input writers with replacement identity attachments and depth testing stamp zero and invalidate only their covered pixels. Offscreen draws that bind neither main depth nor an input attachment are ignored. Unexpected visibility-affecting draws, untracked command lists, relevant clears after known writers, and unsupported binding state invalidate the pass certificate. Uncertified raw data is diagnostic only. A certified pass still requires per-pixel nonzero bounded identity, valid/covered flags, the participation witness and matching final depth. A raster-local identity is independent of DXR; mapping it to a TLAS hit is a separate operation. Reconstruction requires that correspondence before setting its exact-ray ownership bit; final radiance admission is downstream.

## Resolution and fences

The engine attachment extents match the engine depth/MAIN attachments; they may be display-sized. The shared DX12 snapshots are allocated at the internal world render size and copy only that rectangle. Consumer dimensions must equal the snapshot dimensions. The four integer planes consume 64 bytes per internal pixel, excluding evidence, engine targets and alignment. The evidence snapshot has its own shared fence. Consumers must retain the immutable RawInputFrame and wait for both D3D11 producer fence values on the DX12 queue before transitioning COMMON -> NON_PIXEL_SHADER_RESOURCE; return shared textures to COMMON after use. The per-draw table is immutable upload memory retained with the frame; its backing allocation grows in 64 KiB increments and is reused when the frame slot retires. The producer also publishes a CPU-owned materialSources vector indexed by materialOrdinal minus one, with copied Lighting property flags, TXST paths, NIF parameters, alpha, clamp and UV transform. Missing metadata is not a material recipe; Worker 05 owns interpretation and residency. Slots are reused only after producer retirement and release by consumers; no CPU readback is required.

## Coverage / validation boundary

Static Lighting, skinned Lighting (including raster-local skin partitions), landscape, projected and specialized Lighting permutations now use the original interpolants rather than the standalone capture shader. Ordinary cutout alpha testing and the additional dither mask are retained, with raw UV rather than shaded/parallax UV. Grass, distant trees and deferred Effect publish raw inputs through their original permutations, with flat instance identifiers; Effect retains the shared visibility/alpha prefix and exits before lighting. Recognized GPU-counted draws have bounded local identities; unrecognized writers reject conservatively. Lighting uses raster-local records for skinned partitions and partial ranges, and includes skinned projection interpolants and seam-adjusted base weights. Borrowed seam weights/texture identity, skinned projector constant parity, displacement-dependent cutouts, special alpha/LOD combinations, Lighting multi-instance varying propagation, and non-Lighting material source resolution remain incomplete. Texture/projector residency and native material evaluation remain downstream. A raster-local identity can be decoded by ReadRawVisibility without a TLAS match; Worker 05 must consume the copied material metadata and implement evaluation. Forward visibility, arbitrary foreign shaders and VR are not covered by this opaque-pass contract. Unknown writers reject the whole certificate rather than pretending their per-pixel output is known.

Required Windows validation: FXC compile all permutation classes, verify integer RTV and blend compatibility in debug layer, compare raw IDs/depth at overlapping/coplanar/alpha-tested draws, exercise partial indexed ranges and skin partitions, verify actual internal render sizes with FSR, and verify both fence lifetimes. The source contract is versioned separately from a runtime coverage claim.

## Coverage extension 2 — coordination with Workers 04 and 05

- Lighting propagates the original SV_InstanceID through the original vertex output. The existing flattened v6 draw-local identity applies; generated draws retain bounded counts, never inferred TLAS correspondence.
- The GPU layout and 80-byte record are unchanged. Optional flag bit 23 in BasisFlags.w denotes borrowed landscape lanes: the six base weights and two borrowed weights occupy the eight existing half lanes. The decoder exposes borrowedLandscape separately; ordinary auxiliaryKind values remain unchanged. Worker 05 must handle this explicitly; snow amount and LOD fade are not simultaneously carried in this seam variant. No incompatible reinterpretation of unflagged landscape data.
- RawInputFrame::drawSourceViews is an optional CPU-side array parallel to drawRecords. Each shared RasterSourceViews identifies the shader class and requested D3D11 SRVs at original slots 0–15, 80–97, and 107–112. Null means unavailable. In particular slots 107–112 identify borrowed color/normal/RMAOS views. Strong references protect view identity and lifetime, not content immutability or automatic DX12 accessibility. Worker 05 owns acquisition/transfer and residency; do not mistake a view for a resident descriptor. Explicitly bound resources may have been auto-unbound by D3D11 hazards; consumer must validate resources before use. No resource name or TXST is fabricated for non-Lighting inputs.
- Worker 04's revision-aware Lighting source cache is preserved. Source-view tracking is seeded once at the pass boundary and updated at PSSetShaderResources; snapshots are shared across draws with unchanged bindings. No per-draw PSGetShaderResources, path copies or material interpretation is added. Retired material value rows are reused.
- Sparkle alpha samples its projected UV while published UV remains raw. General displacement-dependent cutouts, exact LOD alpha parity, combined snow/LOD and borrowed seam payload, skinned projector constant ownership and tessellated instance propagation remain outstanding. Engine MRTs retain MAIN/depth-compatible dimensions; internal-resolution snapshots remain the independent DX12 allocation.
